Questions we get every week

Or ask the assistant — it answers from this same knowledge base.

Does solar still pay off with Texas net metering changes?

Austin Energy's Value of Solar credit is currently 9.91¢/kWh and is applied to your bill monthly. Pairing with a battery lets you shift usage off peak rates, which is where most of the extra savings come from in 2026.

How long does the roof warranty last?

Panels carry a 25-year product and production warranty, microinverters 25 years, and our workmanship and roof-penetration warranty is 10 years, transferable if you sell the house.

What happens during an outage?

Without a battery, the system shuts down for line-worker safety. With a battery, the home islands automatically in under a second — most customers only notice because the lights flicker once.

Do you handle the permits and the utility paperwork?

Yes. City of Austin permit, Austin Energy or Pedernales interconnection, HOA submissions if needed, and the final inspection are all ours. You sign; we file.

Can I add a battery later?

Yes, if we install an AC-coupled system now. We size the main panel and conduit runs for it on day one, so a later battery is a one-day job rather than a rewire.

About the assistant on this page

The part the demo is actually about — here is what it does and how it is built.

Works with zero setup

Out of the box, "Sunny" runs a local retrieval engine in the browser: intent scoring over a curated knowledge base, conversational context for follow-ups, and guided slot-filling to capture a lead. No API key, no backend, no cost per message.

Swaps to a real LLM

Open the assistant's settings and paste an Anthropic or OpenAI key. The widget then streams live model responses token-by-token, grounded in the same knowledge base via a system prompt, with the local engine as an automatic fallback if the call fails.

Speaks and listens

The microphone uses the browser's SpeechRecognition API for voice input, and replies can be read aloud through speech synthesis. Both degrade gracefully where the browser doesn't support them.

Keys entered in the widget stay in your own browser's localStorage and are sent only to the provider you choose, directly from your browser. Nothing is proxied through this site — it is a static page on GitHub Pages. For production I'd put the key behind a server-side proxy instead; the bring-your-own-key mode exists so this demo can be tried without one.
